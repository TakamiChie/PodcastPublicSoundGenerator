# Podcast Public Sound Generator

このアプリケーションは、ポッドキャスト音源にBGMを重ねてダウンロードできるJavaScriptアプリケーションです。

## 使い方

### ローカル環境

1. `bgm/` フォルダーにBGMのMP3ファイルを入れてください。
2. `python fileget.py > files.json` を実行してファイルリストを生成します。
3. ブラウザで `index.html` を開きます。
4. ポッドキャスト音声をアップロードし、BGMを選択すると、合成されたWAVをダウンロードできます。
5. カバーアートはプレビュー後、ダウンロード時に3000px×3000pxのPNGとして保存されます。

### GitHub Pages

1. リポジトリをGitHubにプッシュします。
2. GitHub Pagesを有効にし、`index.html` をルートに設定します。
3. ブラウザでアクセスすると、BGMとテンプレートがGitHub APIから自動取得されます。

## 機能

- BGMの自動選択（ファイル名から）
- 音量正規化（簡易）
- ハイパスフィルタ
- BGMミックス（イントロ、本編、アウトロ）
- カバーアート生成
- アーカイブ音声ダウンロード（オリジナル）
